The project

A review layer for road-camera video.

Our prototype samples fixed-camera footage, detects road users, applies temporal rules, estimates risk cues, and creates an annotated video for human review.

YOLOv8nCUDAOpenCVStreamlitLocal-first
DetectLocate road users with a compact COCO-pretrained detector.
ReviewShow candidate intervals and visual pointers in an annotated clip.
Run locallyKeep processing on the machine; no hosted inference API is required.
Stay cautiousUse event windows as prompts for review, not final incident decisions.
Important: event labels are heuristic candidates. The sample footage has no ground-truth labels, so this site makes no accuracy or incident-confirmation claims.
